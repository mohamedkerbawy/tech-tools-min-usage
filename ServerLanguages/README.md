## Java

**Java** is a high-level Programming Language.

**Apache Maven** is a build tool for Java projects. Using a project object model (POM), Maven manages a project's compilation, testing, and documentation.

[Java Website](https://www.oracle.com/java/) | [maven Website](https://maven.apache.org/)

[Java Tutorials Website](https://dev.java/learn/)

## Node.js

**Node.js** is a cross-platform JavaScript runtime environment that lets developers create servers, web apps, command line tools and scripts.

**npm** is the standard package manager for Node.js.

[Node.js Website](https://nodejs.org/) | [npm Website](https://www.npmjs.com/)

[Node.js Guide Website](https://nodejs.org/learn)
