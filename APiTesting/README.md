Postman is the API platform for using, building, and testing APIs

[Postman Website](https://www.postman.com/)

[Postman Docs Website](https://learning.postman.com/)

## SoapUI

SoapUI is a tool for testing Web Services; these can be the SOAP Web Services as well RESTful API or HTTP based services.

[SoapUI Website](https://www.soapui.org/)

[SoapUI Docs Website](https://www.soapui.org/docs)

[Get Started with SoapUI](https://drive.google.com/file/d/1LtcNVi0BiktbVYBaVkTjrCWnKd2jXJgh/view?usp=drive_link)

REST Assured is a Java library for test and validate API REST services.

[REST-Assured Website](https://rest-assured.io/)

[REST-Assured Usage Guide](https://github.com/rest-assured/rest-assured/wiki/Usage)
