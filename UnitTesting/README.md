## Mocha and Chai

**Mocha** is a JavaScript test framework for Node.js programs.

**Chai** is an assertion library that is used chiefly alongside Mocha.

[Mocha Website](https://mochajs.org/) | [Mocha GitHub](https://github.com/mochajs/mocha) | [Mocha Guide](https://mochajs.org/getting-started/)
